# 🧠 РебусДень

**Ежедневная социальная головоломка-ребус.** Один ребус в день — на всю планету. Решаешь → получаешь Wordle-сетку результата → делишься ею с друзьями → держишь серию 🔥.

**🌐 Онлайн: https://proff525-design.github.io/rebusden/**
(открой на телефоне → меню браузера → «Установить приложение» — игра заработает офлайн)

**📱 Android APK (TWA):** `РебусДень-1.0.0.apk` (Git LFS, релиз на GitHub) — Trusted Web Activity поверх живого PWA: иконка в лаунчере, `display: standalone`, полноэкранный режим (для скрытия адресной строки поднят `assetlinks.json` в корне хоста). Подпись: v2+v3, пакет `com.proff525design.rebusden`, minSdk 24 / targetSdk 36. Сборка воспроизводима — см. `BUILD_APK.md` и `build_apk.ps1`.

## Как запустить локально

Открой `index.html` в браузере (двойной клик — сервер не нужен), либо:

```bash
npx serve .
```

## Почему именно эта идея (анализ спроса, 2026)

- **Puzzle — единственный жанр мобильных игр с ростом загрузок в Q2 2026** (Sensor Tower), выручка IAP +17% г/г.
- **Hybrid-casual** — самая доходная модель казуалки: простая механика + мета-прогресс + монетизация рекламой.
- Виральная «сетка результата» решает главную беду рынка — **дорогой трафик**: игрок сам приводит друзей.
- Подписок нет — рынок устал от подписок (subscription fatigue).

## Что внутри (MVP v2)

| Файл | Назначение |
|---|---|
| `index.html` | Разметка: игра, тренировка, архив, модалки правил/статистики/«рекламы» |
| `style.css` | Тёмная тема, карточки со стеклом, анимации, мобильная вёрстка |
| `puzzles.js` | Пул из **32 проверенных ребусов** + правил знаков |
| `game.js` | Логика: ходы, оценка букв, серия, статистика, шеринг, архив, **конструктор**, PWA |
| `sharecard.js` | Генератор **PNG-карточки**: результат дня, тренировки и **челленджа другу** |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | PWA: установка на телефон, офлайн-работа |
| `_check.js`, `_smoke.js` | Автотесты: 37 + 36 = **73 проверки, 0 ошибок** |
| `_e2e.js` | E2E в jsdom против реального `index.html`: 27 проверок (`npm i jsdom && node _e2e.js`) |

**Механики:**
- 5 попыток, буквенная подсказка 🟩🟨⬛ как в Wordle
- Знаки ребуса: запятая слева/справа, буква сверху/снизу, ⟲ «назад»
- Серия дней (streak) + рекорд, статистика с распределением попыток
- Архив за 7 прошлых дней, бесконечная тренировка
- Подсказки: бесплатная (слово на картинке) и за «рекламу» (rewarded ad — демо)
- **🧩 Конструктор**: выбери картинку + знак (29 картинок, 32 проверенные комбинации) → «Играть», «Бросить вызов» или «Карточка» (PNG без ответа!)
- **🔗 Челлендж по ссылке**: «Бросить вызов» кладёт в текст ссылку `…#c=p10` — друг открывает её и **сразу играет именно твой ребус**; ответ друга считается в отдельной статистике «Челленджи», серия дня не затрагивается
- Три канала шеринга: **текстовая сетка** (со ссылкой на игру), **PNG-карточка** и **ссылка-челлендж**
- PWA: установка на домашний экран, офлайн-режим

**Итого тестов: 100 проверок (37 данные + 36 логика + 27 E2E), 0 ошибок.**
